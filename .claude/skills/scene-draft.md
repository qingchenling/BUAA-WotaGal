# Skill: 起草一场戏 (scene-draft)

## 触发场景
需要为《光轨》创作一场新戏。

## 执行流程

1. **确认上下文**
   - 这场戏发生在第几周 / 哪个事件
   - 涉及哪些角色
   - 触发条件是什么（固定周目 / 判定触发 / 进线选项）
   - 玩家需要先读取的剧情文件

2. **读取参考资料**
   - 涉及角色的 `人设.md`
   - 对应剧情线文件（林若线 / 叶子线）
   - `开发指导.docx` 中对应的数值/触发条件（如需核对机制）

3. **输出剧本**
   按以下格式输出：

```
## 场景信息
- 周数/事件：
- 触发条件：
- 涉及角色：
- bg + BGM：

## 剧本
[按叶子线剧情.md的详细格式输出完整对话+描写]

## 创作意图
- 这场戏在剧情弧线中的位置：
- 推动的角色变化：
- 铺垫/回收的伏笔：
```

4. **冲突检查**
   - 与已有剧情是否有时间线冲突
   - 角色台词风格是否一致
   - 差分使用是否合理
