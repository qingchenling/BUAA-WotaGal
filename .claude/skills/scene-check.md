# Skill: 剧情一致性检查 (scene-check)

## 触发场景
新增或修改了剧情场景后，需要检查与已有内容的一致性。

## 检查清单

### 角色一致性
- [ ] 台词风格符合人设（对照 `人设.md`）
- [ ] 情感状态与当前周数的剧情弧线匹配
- [ ] 差分代码使用正确（无越级跳跃）

### 时间线一致性
- [ ] 周数正确（W0-W20）
- [ ] 与相邻周的事件不冲突（如W9烤肉团建时某人不应已退社）
- [ ] 社团人数变化序列正确

### 剧情逻辑
- [ ] 触发条件与开发指导中的数值设定一致
- [ ] 进线选项互斥逻辑正确（选了A则B不应出现）
- [ ] 信息揭露顺序合理（角色不知道的事不应在不合理的时机说出来）

### 伏笔与回收
- [ ] 新增剧情是否引用了尚未发生的事件（时间悖论）
- [ ] 已有的伏笔是否在本场景中得到了应有的推进
- [ ] 新增的伏笔是否在后续有回收计划

### 重复与冲突
- [ ] 是否已有类似场景（避免重复）
- [ ] 角色发言是否与已有场景中的发言矛盾

## 输出格式
```
## 一致性检查报告

### 通过 ✓
- 列举通过的项目

### 警告 ⚠（建议修改）
- 问题描述 → 建议

### 阻断 ✗（必须修改）
- 问题描述 → 必须修改的原因
```
