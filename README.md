讲讲文件结构
开发指导有点落伍了，全是ai写的
game文件夹外的头是之前教程项目自带的美术资源，icon什么的没有替换，以及分发手机安卓需要的文件不需要修改
game里面主要是script这里脚本，使用renpy（python）
gui.rpy option.rpy screens.rpy script.rpy 都是系统预设的，主要是外面那个galgame1壳子用的现成的轮子，把script的接口直接接到了core里面然后开始跑内部的数据。（但是好像编译的时候所有rpy是同时编译的所以不用import，也许之后试试重构）
主要写的部分在game/script/core，
所有变量定义在datastore里，方法在api，游戏流程在gameflow，（主要是大循环会做哪几类事件）然后把screen（主要是地图ui拆掉），故事文本实现在story里，各个地点练习的文本在location里，主要是日常的数值加点（也许应该与screen里的map合并？），我感觉解耦应该还行
