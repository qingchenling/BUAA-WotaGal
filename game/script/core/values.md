# 数值策划文档

## 一、设计目标

- 16 周一个周目，每周一次练习机会
- 技能池 60 个，一个周目接触 18-20 个
- 个人技艺值范围 **1-1000**，起始 100
- 熟练度范围 **0-100**（不变）
- 双流派平衡：
  - **广度流**：浅尝大量技，吃 0→30 熟练度区间的迅猛红利，期末 ps ~750
  - **深度流**：精练 3-4 个技冲满，靠练满奖励跳升 ps，期末 ps ~1000
- 深度流约束：一周目最多圆满 2 个高难技（d3），或最多 5 个低难技（d1）

---

## 二、技能池结构

总技能数 60 个，按难度分三档：

| 难度 | 数量 | 说明 |
|------|------|------|
| 1 | 25 | 基础技，易学易精，练满奖励小 |
| 2 | 25 | 进阶技，需要一定技艺值积累 |
| 3 | 10 | 高阶技，练满回报极大但耗时长 |

初期用 `技1` ~ `技60` 占位命名，后续替换为实际名称。

数据结构：
```python
{
    "id": 1,
    "name": "技1",
    "difficulty": 1,     # 1/2/3
    "mastery": 0,         # 0-100
    "charm": 3,           # 演出魅力值（本系统暂不涉及）
}
```

## 三、熟练度（Mastery）公式

```
effective_skill = ps / 6

gain = max(1, int(effective_skill × mastery_decay / difficulty))

mastery_decay = 1.0 - 0.7 × (mastery / 100)
```

### 为什么是 `/6`

ps 范围 1-1000，旧公式量级是 ps=18-100。除以 6 后，`effective_skill` 在 ps=100 时 ≈ 17（等于旧版 18），ps=1000 时 ≈ 167。公式逻辑不变，只是 ps 量级放大了。

### 衰减曲线

| 当前熟练度 | mastery_decay | 阶段感受 |
|-----------|---------------|---------|
| 0 | 1.00 | 新手红利，进步最快 |
| 30 | 0.79 | 仍很快，广度流主要吃这段 |
| 50 | 0.65 | 过半，明显放缓 |
| 70 | 0.51 | 需要耐心投入 |
| 90 | 0.37 | 最后冲刺，缓慢 |
| 100 | 0.30 | 大成后仍可练但收益低 |

### 各 ps 节点下的 gain 速查（mastery=0, 天气=1.0）

| ps | eff_skill | d1 gain | d2 gain | d3 gain |
|----|-----------|---------|---------|---------|
| 100 | 17 | 17 | 8 | 5 |
| 200 | 33 | 33 | 16 | 11 |
| 300 | 50 | 50 | 25 | 16 |
| 400 | 67 | 67 | 33 | 22 |
| 500 | 83 | 83 | 41 | 27 |
| 600 | 100 | 100 | 50 | 33 |
| 800 | 133 | 100→衰减 | 66 | 44 |
| 1000 | 167 | 100→衰减 | 83 | 55 |

> mastery=0 时 d1 gain 超过 100 的部分会被熟练度上限截断（一次最多到 100）。实际 gain 还要乘 mastery_decay。

### 各难度练满所需周数

| ps | d1 练满 | d2 练满 | d3 练满 |
|----|---------|---------|---------|
| 100 | ~10 周 | ~19 周 | 练不满 |
| 200 | ~5 周 | ~9 周 | ~15 周 |
| 300 | ~4 周 | ~6 周 | ~10 周 |
| 500 | ~3 周 | ~4 周 | ~6 周 |
| 700 | ~2 周 | ~3 周 | ~4 周 |
| 1000 | ~1-2 周 | ~2 周 | ~3 周 |

> d3 在 ps<300 时基本练不满，天然强制玩家不能开局冲高难技。到 ps 600+ 才开始有效率。

## 四、个人技艺值（personal_skill）成长

范围 **1-1000**，起始 **100**。

### 来源

| 来源 | 数值 | 说明 |
|------|------|------|
| 每次练习（每次 pick） | +20 | 无论练什么，固定增长 |
| 练满 d1 技 | +30 | 容易拿，但回馈小 |
| 练满 d2 技 | +60 | 中等回报 |
| 练满 d3 技 | +150 | 大奖，但需要高 ps 才练得满 |

### 正反馈循环

```
练满技 → ps 跳升 → effective_skill 提高 → 后续 gain 更大 → 更容易练满下一个技
```

- d3 的 +150 是质变跳升，但前提是先用 d1/d2 把 ps 堆到 300+
- d1 的 +30 容易拿，广度流靠数量（5 个 d1 = +150 = 一个 d3）
- 深度流从练满奖励拿到的 ps 更多，但广度流接触的技多，下个周目起点高

## 五、选技机制

### 选项构成

候选池 = **已知技槽位（2 个固定）** + **新技槽位（随 ps 增长）**：

| ps | 候选总数 | 已知技 | 新技 |
|----|---------|--------|------|
| 0-199 | 3 | 2 | 1 |
| 200-399 | 4 | 2 | 2 |
| 400-599 | 5 | 2 | 3 |
| 600+ | 6 | 2 | 4 |

### 每次可选技数

| ps | 可选数 |
|----|--------|
| 0-299 | 1 |
| 300-599 | 2 |
| 600+ | 3 |

### 已知技槽位抽取规则

从 `mastery > 0` 的技中按权重随机抽：

```
weight = max(1, 100 - mastery)
```

mastery 越**低**权重越大。已知技不足 2 个时，空位用新技填充。

### 新技槽位抽取规则

从 `mastery == 0` 的技中均匀随机抽。

## 六、双流派 16 周模拟

### 广度流（见一个学一个，蹭 0→30 红利）

策略：每次优先学新技，已知技槽位刷到才顺便练。每个技蹭最迅猛的 0→30 区间就走。

| 周 | ps | 选 | 动作 | 已学 | 已满 |
|----|-----|----|------|------|------|
| 1 | 100 | 1 | 学技1(d1) m:0→17 | 1 | 0 |
| 2 | 120 | 1 | 学技2(d1) m:0→20 | 2 | 0 |
| 3 | 140 | 1 | 学技3(d1) m:0→23 | 3 | 0 |
| 4 | 160 | 1 | 学技4(d2) m:0→13 | 4 | 0 |
| 5 | 180 | 1 | 学技5(d1) m:0→30 | 5 | 0 |
| 6 | 200 | 2 | 学技6+学技7 | 7 | 0 |
| 7 | 240 | 2 | 学技8+练技1(17→57) | 8 | 0 |
| 8 | 280 | 2 | 学技9+学技10 | 10 | 0 |
| 9 | 320 | 2 | 学技11+练技1(57→90) | 11 | 0 |
| 10 | 360 | 2 | 学技12+**练满技1**(90→100) | 12 | 1 |
| | | | → ps+30=390 | | |
| 11 | 410 | 2 | 学技13+练技2(20→80) | 13 | 1 |
| 12 | 450 | 2 | 学技14+**练满技2**(80→100) | 14 | 2 |
| | | | → ps+30=480 | | |
| 13 | 500 | 3 | 学技15+16+练技3(23→70) | 16 | 2 |
| 14 | 560 | 3 | 学技17+18+练技3(70→100)MAX | 18 | 3 |
| | | | → ps+30=590 | | |
| 15 | 610 | 3 | 学技19+20+练技4(13→65) | 20 | 3 |
| 16 | 670 | 3 | 练技4(65→100)MAX+练技5+练技6 | 20 | 4 |
| | | | → ps+30=700 | | |

**期末**：ps ≈ **730**，已学 **20** 个，练满 **4** 个（d1×4）。

### 深度流（4 技精练路线）

策略：开局选定一个 d1 快速冲满拿首奖，ps 跳升后切 d2，最后冲 d3。

| 周 | ps | 选 | 动作 | 已学 | 已满 |
|----|-----|----|------|------|------|
| 1 | 100 | 1 | 学A(d1) m:0→17 | 1 | 0 |
| 2 | 120 | 1 | 练A 17→37 | 1 | 0 |
| 3 | 140 | 1 | 练A 37→60 | 1 | 0 |
| 4 | 160 | 1 | 练A 60→85 | 1 | 0 |
| 5 | 180 | 1 | **练满A**(85→100) | 1 | 1 |
| | | | → ps+30=210 | | |
| 6 | 230 | 2 | 学B(d2)+学C(d1) | 3 | 1 |
| 7 | 270 | 2 | 练B(0→45)+练C(0→45) | 3 | 1 |
| 8 | 310 | 2 | 练B(45→89)+练C(45→89) | 3 | 1 |
| 9 | 350 | 2 | **练满B**(89→100)+**练满C**(89→100) | 3 | 3 |
| | | | → ps+60+30=440 | | |
| 10 | 460 | 2 | 学D(d3)+练D(0→38) | 4 | 3 |
| 11 | 500 | 2 | 练D(38→74) + 学E(d1) | 5 | 3 |
| 12 | 540 | 2 | 练D(74→98) + 练E(0→45) | 5 | 3 |
| 13 | 580 | 3 | **练满D**(98→100)+练E(45→85)+学F | 6 | 4 |
| | | | → ps+150=730 | | |
| 14 | 760 | 3 | **练满E**(85→100)+学G+学H | 8 | 5 |
| | | | → ps+30=790 | | |
| 15 | 810 | 3 | 练F(0→67)+练G(0→67)+学I | 9 | 5 |

| | | | → ps+60=930 | | |

**期末**：ps ≈ **930**，已学 **9** 个，练满 **7** 个（d3×1 + d2×1 + d1×5）。

---

### 流派对比

| | 广度流 | 深度流 |
|----|--------|--------|
| 期末 ps | ~730 | ~930 |
| 已学技数 | 20 | 9 |
| 练满技数 | 4（均为 d1） | 7（d3×1 + d2×1 + d1×5） |
| 风格 | 工具箱广，什么都略懂 | 绝活哥，顶尖战力 |
| 下个周目 | 大量技有 20-60 基础 | ps 碾压，学新技极快 |
| 演出优势 | 组合灵活，见招拆招 | 高难技震慑力强 |

> 两者综合实力相当，差异在玩法风格。广度流知道更多技但不够深，深度流技少而精，ps 高所以后续学什么都快。

## 七、参数总表

```python
# ===== 基础范围 =====
PS_MIN = 1
PS_MAX = 1000
PS_START = 100
MASTERY_MAX = 100
PS_DIVISOR = 6                 # effective_skill = ps / DIVISOR

# ===== 熟练度 =====
MASTERY_DECAY_RATE = 0.7       # 衰减系数，0.7 → mastery=100 时 decay=0.3

# ===== ps 增长 =====
PS_GAIN_PER_PRACTICE = 20      # 每次 pick 的固定增长
MASTERY_MAX_BONUS_D1 = 30      # 练满难度 1 奖励
MASTERY_MAX_BONUS_D2 = 60      # 练满难度 2 奖励
MASTERY_MAX_BONUS_D3 = 150     # 练满难度 3 奖励

# ===== 选技机制 =====
KNOWN_SLOTS = 2                # 已知技固定槽位数
OPTIONS_BASE = 3               # 基础候选总数（ps 0-199）
OPTIONS_STEP = 200             # ps 每增长此值，候选 +1 → ps/200 + 3
PICKS_BASE = 1                 # 基础可选数（ps 0-299）
PICKS_STEP = 300               # ps 每增长此值，可选 +1 → ps/300 + 1
MAX_PICKS = 3

# ===== 已知技抽取权重 =====
MASTERY_WEIGHT_OFFSET = 100    # weight = max(1, OFFSET - mastery)
```
