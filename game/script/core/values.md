# 数值策划文档

## 一、核心设计理念

### 三种数值的分工

| 数值 | 含义 | 范围 | 谁更高 |
|------|------|------|--------|
| **技艺值** (ps) | 学技能力，代表「会多少」「学多快」 | 1-1000 | 广度流 |
| **熟练度** (mastery) | 单个技的掌握深度 | 0-100（显示）/ 0-500（隐藏） | 深度流 |
| **名气** (fame) | 播放量/知名度，表演产出 | 1000-5000（全周目累计） | 深度流 |

### 流派分化逻辑

```
广度流：大量学新技 → ps 高 → 学技越来越快 → ps 更高
         ↓
        熟练度浅（20-80），名气积累慢但稳

深度流：少量技反复练 → mastery 溢出到隐藏区间 → 表演时名气爆发
         ↓
        ps 涨得慢，但几个绝活能打出碾压级名气
```

- **技艺值高 = 会学**，广度玩家见一个学一个，学技能力自然增长快
- **熟练度深 = 能演**，深度玩家把技练到「大成」以上，表演时变现为大量名气
- 两种流派各有所长，不存在谁碾压谁

## 三、熟练度（Mastery）公式

### 显示值 vs 隐藏值

- **显示值** (`mastery`)：0-100，到 100 封顶显示
- **隐藏值** (`hidden_mastery`)：0-500+，持续累加，永不封顶
- 隐藏值 ≤100 时，显示值 = 隐藏值
- 隐藏值 >100 时，显示值恒为 100，但文字颜色随隐藏值变化

### 公式

```
effective_skill = ps / 6

# 阶段 1: hidden_mastery ≤ 100 — 线性衰减
decay = 1.0 - 0.7 × (hidden_mastery / 100)

# 阶段 2: hidden_mastery > 100 — 渐进式衰减（接续 100 处的 0.3）
overflow = hidden_mastery - 100
decay = 0.3 / (1.0 + overflow / 100)

gain = max(1, int(effective_skill × decay / difficulty))
```

### 衰减曲线完整表

| 隐藏熟练度 | decay | 显示 | 阶段感受 |
|-----------|-------|------|---------|
| 0 | 1.00 | 0 | 新手红利 |
| 30 | 0.79 | 30 | 进步最快的一段 |
| 50 | 0.65 | 50 | 过半，开始放缓 |
| 70 | 0.51 | 70 | 需要耐心 |
| 90 | 0.37 | 90 | 最后冲刺 |
| **100** | **0.30** | **100（显示封顶）** | 「大成」 |
| 150 | 0.20 | 100 | 绿 → 蓝 |
| 200 | 0.15 | 100 | 「入化」 |
| 300 | 0.10 | 100 | 「登峰」 |
| 400 | 0.075 | 100 | 紫 → 金 |
| 500 | 0.06 | 100 | 「造极」 |

> 100 处公式连续：阶段 1 在 hidden=100 时 decay=0.3，阶段 2 在 overflow=0 时 decay=0.3/1.0=0.3。

### 各 ps 节点 gain 速查（hidden_mastery=0, d1）

| ps | eff_skill | gain | 练到 100 需要 |
|----|-----------|------|-------------|
| 100 | 17 | 17 | ~10 周 |
| 200 | 33 | 33 | ~5 周 |
| 400 | 67 | 67 | ~3 周 |
| 600 | 100 | 100 | ~2 周 |
| 800 | 133 | 100→ | ~1 周 |
| 1000 | 167 | 100→ | ~1 周 |

### 溢出区间 gain 速查（ps=800, d1，深度流后期）

| 隐藏值 | decay | gain | 每 100 溢出需要 |
|--------|-------|------|---------------|
| 100→150 | 0.30→0.20 | 40→27 | ~2 周 |
| 150→200 | 0.20→0.15 | 27→20 | ~3 周 |
| 200→300 | 0.15→0.10 | 20→13 | ~7 周 |
| 300→400 | 0.10→0.075 | 13→10 | ~9 周 |
| 400→500 | 0.075→0.06 | 10→8 | ~12 周 |

> 溢出区间呈「顶部效应」：越往后越难涨，深度玩家投入海量时间才能从 200 推到 500。

## 四、技艺值（ps）成长

技艺值代表「学技能力」，因此**广度流 ps 高于深度流**。

### 来源

| 来源 | 数值 | 触发条件 |
|------|------|---------|
| 学习新技 | +25 | 每次学一个 mastery=0 的技（每人每周首次多加） |
| 每次练习 | +10 | 每次 pick，无论新旧 |
| 练满 d1 | +20 | hidden_mastery 首次达到 100 |
| 练满 d2 | +40 | 同上 |
| 练满 d3 | +80 | 同上 |

### 为什么广度流 ps 更高

- 广度流每学一个新技就 +25，16 周接触 20 个技 = 500 ps 来自新技
- 深度流只接触 9 个技 = 225 ps 来自新技
- 差距约 275 ps，远超练满奖励的差距（深度多拿 ~120）
- 净效果：广度 ps ≈ 850，深度 ps ≈ 750

## 六、表演事件 & 名气（Fame）系统

### 表演排期

固定 4 次表演，发生在指定周目，每次表演**累计**名气：

| 表演 | 周目 | 说明 |
|------|------|------|
| 第 1 次 | 第 5 周 | 初期小演 |
| 第 2 次 | 第 9 周 | 中期汇演 |
| 第 3 次 | 第 14 周 | 后期主舞台 |
| 第 4 次 | 第 18 周 | 终演 |

> 当前游戏循环为 16 周，需要扩展到至少 18 周才能容纳全部 4 场表演。

### 名气公式

```
单技名气 = charm × (hidden_mastery / 10)²

单次表演总名气 = Σ 所有参演技的单技名气
```

平方意味着熟练度对名气的贡献是**非线性**的——高熟练度的技会带来碾压级的名气：

| hidden_mastery | /10 | 平方 | ×charm(3) | 
|---------------|-----|------|-----------|
| 30 | 3 | 9 | 27 |
| 50 | 5 | 25 | 75 |
| 80 | 8 | 64 | 192 |
| 100 | 10 | 100 | **300** |
| 150 | 15 | 225 | **675** |
| 200 | 20 | 400 | **1200** |
| 300 | 30 | 900 | **2700** |

> 一个 mastery=300 的技，名气产出 = 10 个 mastery=100 的技，或 100 个 mastery=30 的技。这就是深度流的投资回报。

### 16+2 周名气模拟

**广度流**（20 技，熟练度分散在 25-70）：

| 表演 | 参演技 | 平均 mastery | 单技名气 | 总名气 |
|------|--------|-------------|---------|--------|
| 第 5 周 | 5 | 30 | 27 | **135** |
| 第 9 周 | 11 | 45 | 61 | **668** |
| 第 14 周 | 20 | 55 | 91 | **1815** |
| 第 18 周 | 20 | 65 | 127 | **2535** |

|------|--------|---------------|---------|------|--------|

### 流派名气对比

| | 广度流 | 深度流 |
|----|--------|--------|
| 第 5 周 | 135 | 250 |
| 第 9 周 | 668 | 960 |

| **累计** | **~5150** | **~6120** |

- 前两次表演差距不大（深度略优）
- 第 14 周开始深度溢出技发力，拉开差距
- 终演时深度单技可抵广度 10+ 技
- 广度流名气也不低（靠数量堆），但深度流的溢出技是质变

### 作弊码：继承开关

输入特定作弊码后，开启**跨周目继承**。效果：

```
新周目开始时：
  - person_skill 保留（不重置为 100）
  - skill_pool 中所有 mastery / hidden_mastery 保留
  - fame 保留
```

作为达成某种**超级结局**的奖励。正常通关不继承，只有输入作弊码才生效。

实现方式：`datastore.rpy` 加一个 `default inherit_unlocked = False`，作弊码将其设为 `True`。`gameflow.rpy` 在新周目开始时检查此标记决定是否重置数值。

## 八、公式与参数速查

### 8.1 公式总汇

| # | 公式 | 说明 |
|----|------|------|
| ① | `effective_skill = ps / 6` | 技艺值折算为有效技艺 |
| ② | `decay = 1.0 - 0.7 × (h / 100)` | 阶段 1 衰减（h ≤ 100） |
| ③ | `decay = 0.3 / (1 + overflow / 100)` | 阶段 2 衰减（h > 100，overflow = h - 100） |
| ④ | `gain = max(1, ⌊effective × decay / difficulty⌋)` | 单次练习熟练度增量 |
| ⑤ | `ps += 25（学新技）+ 10×picks + bonus` | 技艺值周增长 |
| ⑥ | `options = 3 + ps / 200` | 候选技数量 |
| ⑦ | `picks = 1 + ps / 200`（上限 3） | 每次可选技数 |
| ⑧ | `fame = Σ charm × (hidden_mastery / 10)²` | 单次表演名气 |

### 8.2 参数表

#### 基础常量

| 参数 | 值 | 影响 |
|------|-----|------|
| `PS_START` | 100 | 开局学技速度。↑ 则前期练满更快，↓ 则前期更慢 |
| `PS_MAX` | 1000 | 技艺值天花板。↑ 则后期成长空间更大 |
| `PS_DIVISOR` | 6 | 技艺→熟练度的转化率。↓ 则 gain 整体变大，全局练满加速 |
| `MASTERY_DISPLAY_MAX` | 100 | 显示封顶值。只影响 UI，不影响隐藏值 |

#### 熟练度衰减

| 参数 | 值 | 影响 |
|------|-----|------|
| `MASTERY_DECAY_RATE` | 0.7 | 阶段 1 衰减速度。↑ 则前期变慢，↓ 则前期更快但曲线太平 |
| `OVERFLOW_DECAY_HALF` | 100 | 阶段 2 半衰距离。↑ 则溢出更容易堆高，↓ 则溢出更难 |
| `MASTERY_HIDDEN_SOFT_CAP` | 500 | 隐藏值软上限。只影响心理预期，公式不截断 |

#### 技艺值增长

| 参数 | 值 | 影响 |
|------|-----|------|
| `PS_GAIN_NEW_SKILL` | 25 | 学新技奖励。↑ 则广度流 ps 更高，拉开与深度流差距 |
| `PS_GAIN_PER_PRACTICE` | 10 | 每次 pick 固定增长。↑ 则整体加速，两种流派都受益 |
| `PS_MAX_BONUS_D1` | 20 | 练满 d1 奖励。↑ 则练 d1 更有价值 |
| `PS_MAX_BONUS_D2` | 40 | 练满 d2 奖励 |
| `PS_MAX_BONUS_D3` | 80 | 练满 d3 奖励。↑ 则冲高难技的回报更大 |

#### 选技机制

| 参数 | 值 | 影响 |
|------|-----|------|
| `KNOWN_SLOTS` | 2 | 已知技固定槽位。↑ 则更容易练旧技（利好深度），↓ 则更多新技（利好广度） |
| `OPTIONS_BASE` | 3 | 基础候选数。↑ 则选择更丰富 |
| `OPTIONS_STEP` | 200 | 候选数增长阶梯。↓ 则更早进入多候选 |
| `PICKS_STEP` | 200 | 可选数增长阶梯。↓ 则更早进入多选 |
| `MAX_PICKS` | 3 | 单次最多可选。↑ 则后期成长更猛 |

#### 名气

| 参数 | 值 | 影响 |
|------|-----|------|
| `PERFORMANCE_WEEKS` | [5, 9, 14, 18] | 表演触发周。第 17-18 周为剧情空跑 |
| 名气公式 | `charm × (h/10)²` | 平方增长。溢出技的 mastery 每 +100，名气翻 4 倍 |
| `charm` | 3（默认） | 技的魅力值。↑ 则全局名气提升 |

#### 继承

| 参数 | 值 | 影响 |
|------|-----|------|
| `inherit_unlocked` | False | 作弊码改为 True，新周目保留 ps/mastery/fame |

### 8.3 参数调节指南

| 症状 | 调法 |
|------|------|
| 前期练 d1 太慢（>12 周才满） | ↓ `PS_DIVISOR` 或 ↓ `MASTERY_DECAY_RATE` |
| 前期练 d1 太快（<7 周就满） | ↑ `PS_DIVISOR` 或 ↑ `MASTERY_DECAY_RATE` |
| 广度流 ps 领先太多 | ↓ `PS_GAIN_NEW_SKILL` |
| 深度流名气领先太多 | ↓ `charm` 或将名气公式的除数从 10 调为 12 |
| 溢出太难堆（>10 周不动） | ↑ `OVERFLOW_DECAY_HALF` |
| 溢出太容易（2 周推到 300） | ↓ `OVERFLOW_DECAY_HALF` |
| 后期多选来得太晚 | ↓ `PICKS_STEP` |
| 已知技槽位刷不出想练的 | ↑ `KNOWN_SLOTS` 或 ↓ `MASTERY_WEIGHT_OFFSET` |

### 8.4 数值流转图

```
每周练习
  │
  ├─→ 选技（options = 3 + ps/200, picks = 1 + ps/200）
  │     ├─ 已知技 ×2（权重 = 100 - mastery）
  │     └─ 新技 ×N
  │
  ├─→ 练习（公式 ①②③④）
  │     ├─ hidden_mastery ↑
  │     ├─ mastery（显示值）= min(100, hidden_mastery)
  │     └─ 若 hidden_mastery 首次达 100 → ps += bonus
  │
  ├─→ ps 结算（公式 ⑤）
  │     ├─ 学新技 +25
  │     └─ 每次 pick +10
  │
  └─→ 若本周为表演周（5/9/14/18）
        └─→ 名气 += Σ charm × (hidden_mastery / 10)²

期末 / 新周目
  │
  └─→ inherit_unlocked ?
        ├─ False → 重置 ps=100, mastery=0, fame=0
        └─ True  → 全部保留
```
