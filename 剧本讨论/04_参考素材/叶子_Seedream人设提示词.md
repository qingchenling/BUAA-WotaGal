# 叶子 · Seedream 4.0 人设提示词（三格：正面 / 侧面 / 脸部特写）

## 本轮只做三件事

1. **正面全身**
2. **侧面全身**
3. **脸部大特写**

不加八表情、不加底部小细节圈、不加托特包和荧光棒，也不加背视图。先把比例、脸型、发型、服装轮廓和配色定下来。

## 设定

- 20 岁，中国女大学生，165cm，直博生/学生会干事，叶子的幼驯染。
- 头身比 **7–7.5**，高腰线、长腿，清瘦但不幼态。
- 脸型：**更圆的小圆脸**，脸颊饱满，下颌柔和，下巴短；小鼻、小嘴。
- 眼睛：**眼距略近**，约 0.8 个眼宽；蓝色虹膜 + 深一点的矢车菊蓝瞳孔，两个高光。
- 发型：**半扎发**，前端空气刘海保留；发尾内扣，一侧留几缕碎发，小蓝色发带 + 银发夹。
- 发色：**蜂蜜棕/浅栗色**，不要亮黄；黄色只放在衣服上。
- 服装：**奶油黄短款结构感针织外套** + 暖白小尖领衬衫 + 雾蓝领结 + **雾蓝高腰 A 字中长裙（单条深箱褶）** + 白色真皮运动鞋。
- 去掉：工作牌、学生会徽章、袖章、水手领、水手鞋、玛丽珍、乐福鞋、全套校服、托特包。

## 服装的“有型”从哪里来

不是靠加配饰，而是靠**结构和剪裁**：

- **短款外套**：长度到高腰，肩线略挺，领口干净；前襟和袖口有一道很细的雾蓝包边，作为唯一的设计细节。
- **高腰 A 字裙**：干净的腰头，正面一条**深箱褶**，让裙摆有建筑感，但不是制服百褶裙。
- **白衬衫**：小尖领，领口干净，和雾蓝领结形成清楚的视觉中心。
- **白色运动鞋**：把整体拉回大一新生的轻，不要皮鞋。
- 整体原则：**tailored、architectural、fashion-forward but modest**；不是“普通开衫 + 普通裙子”，也不是制服。

## 配色

| 角色 | 颜色 | 用法 |
|---|---|---|
| 主色 | 奶油黄 / butter yellow（低饱和、偏暖，不是柠檬黄） | 短款针织外套 |
| 辅色 | 暖白 / warm white | 衬衫、背景 |
| 点缀蓝 | 雾蓝 / misty periwinkle blue（带一点灰，不刺眼） | 领结、裙子、外套包边 |
| 眼睛蓝 | 深一点的矢车菊蓝 / deeper cornflower blue | 虹膜、瞳孔 |
| 阴影 | 暖灰蓝，不用纯黑 | 皮肤、衣褶暗部 |

奶油黄和雾蓝是低饱和的互补搭配：比“奶油黄 + 宝蓝”柔和，也不容易变成制服感。想要更学院一点，可把裙子换藏青、领结保持雾蓝；这一版先统一雾蓝，整体更轻。

## 使用备注

- 一次生成 2 张，挑脸最稳的那张；重点看：头身比是否够 7–7.5、脸是否够圆、眼距是否偏近、半扎发是否清楚、外套肩线是否挺。
- 如果蓝色太灰，把 `misty periwinkle blue` 换成 `soft cornflower blue`；如果太亮，换成 `dusty slate blue`。
- 如果“有型”还不够，下一轮只改一个变量：把短外套的肩线再挺一点，或把箱褶加深；不要同时动领结、包边和鞋。
- 这一版不要加表情和细节圈；等比例、脸型、发型、服装轮廓确认后，再单独做表情差分和细节图。
