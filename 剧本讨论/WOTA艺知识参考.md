# WOTA艺·实操知识参考

> 本文档供剧本写作参考——记录国内WOTA艺圈子的实际玩法、社团生态、爬台流程、亚文化氛围。

---

## 一、WOTA艺是什么（圈外人一句话版）

一群人拿着荧光棒，配合音乐会打出一套编排好的动作。光线在黑暗里划出轨迹——长曝光拍下来就是"光轨"。跟打Call不一样：打Call是跟着节奏挥棒子，WOTA艺是**全身动作编排**，有起手式、转圈、跳跃，更像舞蹈。

---

## 二、怎么入坑

### 2.1 一般路径
1. 在B站刷到WOTA艺视频——光弧在黑暗里划出轨迹的延时摄影，或者漫展爬台录像
2. 评论区问"这个怎么学" / "零基础可以吗" / "这是哪个社团"
3. 被拉到QQ群 / 在百团大战找到学校社团
4. 第一次去训练——学长演示基础动作，自己跟着比划，手腕角度全不对
5. 买第一对棒子

漫展上的WOTA艺通常以"企划"形式报名——一个节目一个节目地上。

### 2.2 自学 vs 社团
- 很多打师是自学起步的——B站搜教学视频，在自己家阳台/楼道练。被称为**野打**或**散养**。
- 社团提供：有人纠正动作、有场地、有一起爬台的队友
- 大学社团是主要组织形式，但也有社会人打师——工作后还在打的

## 三、装备

### 3.1 棒子

| 类型 | 俗称 | 特点 | 大概价位 |
|------|------|------|------------|
| 化学荧光棒 | 化棒 | 一次性，掰亮，亮度逐渐衰减。颜色固定。用完就扔。 | 几块钱一根 |
| 电子荧光棒 | 电棒 | 充电，可调色/亮度/模式。 | 几十到上百不等 |
| 大mega | — | 高亮度化棒，比普通化棒粗且亮，专为舞台/长曝光设计 | 约20元一根 |

化棒牌子：Lumica（日本）、各种国产。
电棒牌子：King Blade（日本）等。

### 3.2 选棒考虑因素
- **眼缘**：颜色好不好看——打师选棒先看颜色喜不喜欢。没有CRI、色温那些参数对比，就是看眼缘。
- **性价比**：电棒价格跨度大。Rl_3约30多元一根，被称为"性价比之王"；潮汐约90多元一根，主打高科技控制功能。打师选棒时会列参数表、看评测、在群里问"XX和XX哪个好"——跟程序员选键盘差不多。
- **续航**：电棒充电一次能用多久——很重要。
- **耐摔**：高速甩手时棒子脱手飞出去——**飞棒**是比较严重的失误。耐摔的棒子更受欢迎。
- **亮度**：电棒有档位可调。
- **误触**：有些电棒开关设计不好，打动作时容易误按。
- **手感/重量分布**：打师会在意棒子握在手里的感觉。

### 3.3 其他装备
- **手机三脚架**：录练习视频——逐帧回放用。核心装备。
- 手套/护腕——圈内基本没人用。是外界对WOTA艺的误解。

## 四、怎么练

### 4.1 训练流程

WOTA艺的训练存在两条典型路径：

**路径一：强者独狼型**
```
学新技 → 录视频练 → 逐帧看录像找问题 → 改 → 再录 → 再改
```
反复自我纠错，进步快，对自学能力要求高。

**路径二：社团氛围型**
```
前辈带新技 → 学完基础技后学一两个技连 → 编排用的团技 → 每周来一两次训练
```
每周训练以复习和编排为主，学习进度相对缓慢。但这种社员能给社团带来很多欢乐，享受兴趣社团的氛围。作为社长，需要给这类社员多安排编排任务，保持他们的参与感和兴趣。

**重要细节**：
- 对着镜子练不如手机录——因为有些头部动作会对发光角度产生很大影响，眼睛看的和实际打出来的光轨不一样。录下来逐帧看才准。
- WOTA艺的难点不在于"打很多遍"——而在于**发力感**。动作的发力方式对美感影响很大，前辈指导时反复讲的不是"再来"，而是具体的发力细节：手腕怎么转、力从哪个关节出去、肩膀要不要代偿。
- 训练时不完全黑暗——需要能看清身形的亮度，会留一个小灯。光轨效果靠录视频后回放确认。

### 4.2 训练场地
- 大学：舞蹈房（有镜子）、操场角落、教学楼架空层
- 社会人：公园、地下车库、租房（注意楼下）
- 晚上练效果最好——光轨看得清楚
- 场地被赶是常事（被称为出警）——保安、场地管理、投诉噪音

### 4.3 技艺体系

WOTA艺技可以粗浅分为两大类：

#### 关西系
- 讲究发力感，动作相对简洁——大圈、挥、太极圈、六段突、罗曼斯
- 编排追求**整齐度**。日本很多顶级社团动作整齐得像一个人——被称为"复制人军团"。
- 核心审美：一群人动作完全同步，光轨叠在一起。

#### 火把系（Torch）

火把系主要在国内发展，融合了大量日本传入的技，是WOTA艺中变化极多、编排空间极大的领域。

**关于开发指导中的技名**：开发指导里的40个技和技名（雷蛇、OAD、天照、凤凰之舞、凹凸圈等）是游戏设定，部分参考了真实WOTA艺术语，部分为杜撰。具体哪些用真名哪些用化名——可以保留当前设定，不强制与真实圈子对齐。游戏是虚构创作。

##### 火把系概述

**定义与范畴**：Torch（火把）技是WOTA艺中的一个主要分支，其基础动作以圆形光弧为主。关于Torch的概念存在多种指述，当前较为宽泛的定义认为，满足以下条件之一或多个的动作均可视为Torch：①动作中包含特定的基础火把动作（如大圈、八、16、七）；②有显著的Torch元素，是火把技连中常见的动作。

**发展背景**：
- **起源**：早期打师（如ONA等）引入了Torch的基本理念，定义了大圈、八、16、七等基础火把动作。思想源头可追溯至历史更悠久的poi舞蹈（一种利用绳子连接燃烧道具进行旋转的舞蹈）。
- **日本发展**：日本打师（如突运、黑兔、次郎等）在后续数年内创造了背景圈圈、81、双龙等动作，扩充了Torch体系。
- **中国发展**：中国打师（以萤音同盟等为首）对Torch进行了完善，在高级组合与历史研究方面取得成果，形成了当前体系的基本结构。
- **创新现状**：截至当前，符合人体结构与光弧美感的基础火把动作已有超过九成被定义，创新空间主要集中在高级组合与自创技领域。

##### 火把系学习路径

**基础阶段**：从古典火把技（如不知火、玲珑、龙牙、荧照等）与类火把动作入手，建立平面旋转与圈的直觉。

**扩充阶段**：学习2015年左右日本涌现的火把技——平等院系、变速系、五天玩、高尔夫棒球、十会剑系、排闻系等。

**深入阶段**：关注现代中国路打师的作品，可依据个人兴趣方向（如外部超拍、传统组合、逆序组合、乱序组合、高难度等）进行深入钻研。

##### 核心概念

| 概念 | 说明 |
|------|------|
| **顺序性** | 两只手动作转向相同（均为顺时针或逆时针）。例如逆16、双龙等。其"逆"指倒放而非转向。 |
| **逆序性** | 两只手动作转向相反（一手顺、一手逆）。通常由其对应的顺序性动作将其中一只手转向取反而来，命名加"突"字以示区分（如突16）。 |
| **正面形/乱序性** | 光弧表现出流线型或不规则型，难以归类到顺序或逆序的动作。主要包括正面双龙、正面突双龙、正面碰撞圈、大部分牵手系、切八、切16等。 |
| **平面性** | 完成非正面动作时，需确保动作在对准侧平面的方向上完成，以保证镜头中光弧的饱满。 |
| **主手与副手** | 动作某一瞬间，发力或占主导地位的手为主手，另一只跟随摆动的手为副手。部分动作不分主副手。 |
| **同侧与异侧** | 左手在身体左边为同侧，在右边为异侧。右手同理。 |
| **同位与异位** | 异位：两只手节奏错开（如八相对于双手叉）。异位为主的动作更具高级滚动感。 |

**身形、控制与发力**：
- **身形**：决定了打师姿态的成熟度与整体视觉效果。应关注实力过硬的打师的身体细节进行模仿。
- **控制**：重点在于提升光弧的圆润度，需要通过锻炼手腕、小臂、肩膀的灵活度与精准度来流畅完成并修饰动作。
- **发力**：过度发力会破坏光弧的规律性（如使16变成多边形），而全程匀速则显得无力。建议以匀速为主、变速为辅——即光弧控制为主，发力为辅。在一串动作中，找到每个动作部分的发力初始点，其他部分则倾向匀速控制。

##### 基础动作详解：顺序性

**大圈**：以自身面向为基准，顺时针为正大圈，逆时针为逆大圈。每只手各画一个正面圈和一个背面圈，将两圈铺开打出。可通过水平举法辅助记忆与练习。饱满的大圈需要手臂伸直，并不依赖肩膀的带动。追求光弧时上半身随动作走势大幅旋转，追求节拍时只需左右轻微转体。

**八与16序列**：
- 上手/下手定义：在八、16等动作中，手肘交叠时，上方的称为上手，下方的称为下手。上手通常是主手（正八/正16），下手是主手（内/逆16）。
- **八**：本质是双手叉的异位组合。例如以左手为上手的右侧正八，可通过右手画半个叉、左手画半个叉、右手抽离、左手抽离的步骤练习。光弧修饰重点是保证下手的光弧圆度与上手一致，可通过将肩膀向上手发力压下去的方向倾斜来带动。
- **逆八**：与正八打法原理相同（方向相反），通过记叉的位置组合完成。肩膀的带动方向为正八的倒放——倾向将下手发力方向的另一侧倾斜。
- **16（正16/逆16）**：正16实质是两种不同"扣法"（左扣右、右扣左）的正八交替衔接而成。通俗理解为在身体两侧画"小太极"，通过身体旋转衔接。逆16通过两种不同"扣法"的逆八交替衔接而成。诀窍是限制大臂摆动，以肘部为轴心转动小臂（96即是将轴心移至小臂中段的缩小版）。
- **24**：正16与逆16的衔接动作（如正24 = 右侧正16 + 正面小圈 + 左侧逆16）。光弧修饰要求保证左右16与中间小圈大小基本一致。
- **32**：24的变体，中间衔接小圈在循环中出现两次。

**七（米七）序列**：
- **单手七**：先画正面圈，进入头部轨道，大臂从左（右）上运动到右（左）上的同时，小臂和手腕伸直在头后侧面画小圈。
- **双手七**：将两个单手七进行异位组合（通常采用90°错开），即一前一后进入和离开头部轨道。
- **光弧修饰**：普通七的光弧要做得饱满，通过使用小臂、大臂靠近头部来实现。对于外七，则假设一个在头外侧的轴进行旋转。对于贴脸贴肩的七，需用手腕完成以保证大小一致。
- **背身七**：身体180度转到背面完成七，使头部光弧转移至正面。打不圆的主要原因是上半身未完全转过去。

**头花**：
- **万花变体**：将万花（96的缩小）移到头上打。
- **七头花**：通过收缩双手七循环中的正面大圈形成。这是主流打法，注意前后光弧需基本一致。

**31（三十一）**：七与24的衔接动作，周身表现出四个小圈（七一个，24三个）。关键节点是七动作中的"左上、右上"节点。光弧修饰需保证四个圈都能打圆，并通过跟团身形动作移动身形使其向外扩张。

##### 基础动作详解：逆序性

**基本概念**：约定在逆序动作中，左手转向为正则动作为正，左手为逆则动作为逆。由于双手转向相反，平面动作的光弧会在某一点交错，称为"切点"。切点有助于记忆动作或将其分割。

**凸圈（突圈）**：大圈的逆序对应动作。单手一手正大圈，一手逆大圈。组合时需保证一手画正面圈时，另一手画背面圈。光弧修饰：尽可能伸直手臂，通过大幅度旋转肩膀（接近90°）来保证背面圈饱满。切点可人为移动至不同位置（如侧面突圈），产生多种变体。

**突八、突16、突24**：
- **突八（突叉）**：八/双手叉的同位逆序动作。与顺序八类似，有正手在上和逆手在上两种打法。
- **突16**：由两种突八和一种衔接圈（类似缩小的侧面突圈）组合而成。以额头为分界，依次完成第一种突八（汇聚）→切换至第二种突八（汇聚）→完成衔接圈→回到第一种突八。光弧修饰重点在衔接圈，需夹紧大臂，主要用小臂完成，使其大小与突八相当。
- **突24**：顺序24的逆序对应。左右侧的突16通过正面衔接圈进行左右转换，衔接圈由双手按其各自轮换画一上一下两个半圈组成。复杂度高，有九种打法。

**突七、突头花、突31**：
- **突七**：七的逆序对应。突七是异位组合（如正突七是双手轮流面向内的单手七），与16系列的同位性质相反。
- **突头花**：以突七头花为主。可通过压缩法（压突七）或节点法（使用左上、右上节点）上手。
- **突31**：突七与突24的结合。由于复杂性，其正逆属性不仅取决于手转向，还可能出现"正动作逆时针旋转"或"逆动作顺时针旋转"的情况，提供了更多变体。光弧修饰需特别关注正下方的衔接圈，使其不易过大。

**突双龙、突旋龙**：突双龙是双龙的逆序异位组合。突旋龙是旋龙的逆序异位组合。光弧重点修饰背后小圈，由于手转向相反，无法靠惯性带动，需更多依赖手腕和小臂的独立转动。

##### 高级体系

**1. 牵手体系**
- **核心**：击打性转序——通过在身体正面的四个常规击打点位（双肩、双腰）产生击打来触发转序。
- **常用组合**：搓背——双手交替击打身体一侧的后肩与后腰；交叉牵手——双手交叉击打对侧肩膀，画出X型光弧。
- **非击打类衍生**：牵手1——正面正八/逆八的液场互换，靠身体来回转动；牵手圈——一种七的组合，本质是将正/背的七通过180度转向推广到正面，形成正背面衔接的突起效果。

**2. 轮回体系**
- **核心**：一只手（上）做轮回七，另一只手（下）做腰部小圈，是双龙的延伸。
- **轮回七的三种类型**：常规七、侧壁七、正面半花（反过来用时）。
- **命名与组合**：在一组动作中完成N个不同的"七+小圈"即为"N轮回"。
- **衔接规则**：基于"第二种七难以衔接第一种七"等规则，可推导出流畅的连续轮回序列。
- **高级扩展**：旋龙轮回（双旋龙）——双龙与旋龙的结合；迷七轮回——在逆双龙回中加入正/背面双手七；八轮回——将轮回半同位化（头部动作提前半拍），使七与小圈同步，可实现严格的节拍分割。

**3. 后圈体系**
- **定义**：从突圈衍生出的、左右对称的循环动作。包含基于常规突圈的后圈和基于切点移动（肩太极）的后圈。
- **演化方式**：向突圈中添加头部动作（七/轮回七）或腰部动作。
- **典型组合流程**：加一种七 → 将突圈替换为轮回第二种七 → 将小圈替换为加三种七 → 在腰部加小圈对齐 → 将突圈的背圈改为腰部小圈→逆腰圈 → 切点转换（肩太极圈/保圈），可在基础上叠加动作。

##### 高级专题

**碰撞**：一只手持续画正面圈（基准手），另一只手（碰撞手）在光弧重合的瞬间碰到基准手时立即逆序反向画圈，实现上下来回的循环。要点：基准手伸直，碰撞手微弯，碰撞集中在小臂附近，实现空间错位以防打架。应用：碰撞圈24、将碰撞圈移至侧后方、在24中替换八、与其他动作（如搓背搓肩、轮回）组合。

**交错**：在正面构建圆形循环光弧。方法：通过空间错位（一只手在前，一只手在后）和手臂偏向圈的外侧，将"双圈交叠"的光弧合并为"单圈交错"，模拟出正面循环。意义：不仅实现了正面圆形光弧，还开创了"圈光弧薄留"理念——在顺序动作组合中插入单圈交错，可凭空增加几圈、降低行进速度、获得视觉效果。应用：完全31、空想曲下半部分的组合圈。

**半花（头部单圈交错）**：从头花的压缩法衍生而来。正面大圈与头花正面转圈在节拍轨迹上等价，只是大小不同。半花是分离出来的头花前半部分。功能：替代模拟、头部弧薄留。典型应用——半花接力（实现相同转向下双手先后进入/离开头部轨道的顺序交换）、花七（用半花替换标准七）、反转动作（在整体顺时针旋转的大圈中使用逆时针半花完成头部动作，如反转抱肩抱肩、反转完全31）。

**转体**：单脚圈——大圈与360度转身的融合。双脚圈——左右固定三角步的衔接。转体双龙/转体旋龙/转体24/转体交错——将对应动作与转体结合。

**正面形动作扩展**：正面双龙可作为衔接动作方便完成转向变换；正面突龙可利用动作中出现的顺序状态时机（两手转向暂时一致）衔接任意顺序动作或加入单圈交错形成花双龙；切八/切16将正面的八的高阶光弧表现为一条斜线；差分——两只手同时完成不同种类的动作（如抱肩抱肩+单手叉、双龙+16），可用于创造新模式。

##### 火把系总结

Torch体系是一个庞大且逻辑严密的动作系统，以圆形光弧为基础，通过"顺序-逆序"、"同位-异位"、"匀速-变速"等对立统一的概念进行组织与演化。其发展经历了从古典基础动作到现代高级组合的历程。当前基础动作创新空间已有限，但通过深入掌握"牵手"、"轮回"、"后圈"等高级体系，以及"碰撞"、"交错"、"半花"等前沿理论，结合转体、差分等技巧，仍可在动作组合与自创技领域实现丰富且具有个人特色的创造。

### 4.4 熟练度
- 打师之间会讨论"你这个动作的熟练度不够"——手腕角度差一点、节奏慢半拍
- 熟练度不是一次训练能提升的——需要反复打，肌肉记忆
- 难度高的技有"熟练度衰减"——长时间不练会退步

## 五、社团生态

### 5.1 大学社团

**招新**：
- 百团大战摆摊——易拉宝上贴光轨长曝光照片
- B站/QQ空间发招新视频
- "零基础可以来"是标准话术——大部分新人确实是零基础
- 实际留下的人不多——第一周来十个人，一个月后剩两三个

**日常**：
- 每周固定训练时间（周三/周四晚、周末下午是常见的）
- 训练内容：基础技纠错 + 学新技 + 排练企划
- 团建：烤肉/火锅/KTV——唱动漫歌曲，有人跑调，有人全程不唱

**人员流动**：
- 大一刚进来热情最高
- 大二开始分流——有的人成核心成员/社长，有的人慢慢不来了
- 大三以上——课业/实习/考研，"这个学期可能来不了了"
- 退社一般是慢慢淡出，很少正式说"我退社"。把化棒留在训练室是常见的方式

### 5.2 社团之间
- 同城大学社团之间互相串——"远征"去另一个学校一起训练
- 漫展上不同社团的企划同台
- B站互相点赞、评论区互动
- 有竞争但总体是友好的——圈子太小，打来打去就那些人

## 六、爬台

### 6.1 什么是爬台
在漫展/学校活动/livehouse等场合登台表演WOTA艺。台下可能十几个人，可能几百个人。

### 6.2 典型流程

```
报名 → 提交节目说明 → 审核 → 确定时段 → 彩排 → 正式演出
```

漫展爬台需要在活动前通过指定渠道报名，提交节目信息（人数、时长、音乐）。审核通过后分配时段。

### 6.3 爬台前的准备
- 确认化棒数量——多带几根，现场折
- 确认电棒电量——前一天晚上充满
- 确认站位——几个人，谁站哪（编排很重要，以及训练整齐度）
- 设备检查——手机录视频用的三脚架
- "后台紧张"——新人第一次爬台前普遍紧张。深呼吸 / 反复检查装备。
- **新人常见失误**：①开不开棒（忘记折亮化棒或忘记开电棒开关）；②飞棒；③上台时节奏慢了，过后忘动作了，看别人动作呆了一个八拍才回来。

### 6.4 爬台时
- 灯光全暗 → 音乐起 → 化棒折亮 → 开始打
- 台下有人举手机录——"有人录就是好事"
- 出错——棒子折错颜色、动作走形、飞棒——下台后"下次注意"就过去了
- 结束——光灭，喘气，下台。队友互相拍肩膀

### 6.5 爬台后
- 看别人录的视频，逐帧分析自己哪里打得不好
- 把视频传B站——播放量一开始很少，慢慢积累
- 弹幕/评论区互动
- 团建——演完去吃一顿（再加唱K）

### 7.1 B站
- 主要阵地。搜"WOTA艺"标签能看到大量视频

- 每个社团有自己的群

### 7.3 争议与节奏

## 九、游戏里需要的那种"感觉"

### 9.1 圈外人看WOTA社
- "一群人在黑暗里甩荧光棒"——看不懂，但好像挺酷的
- 晚上路过舞蹈房会看到奇怪的光
- 百团大战摊位前——易拉宝上那些长曝光照片很吸引眼球
（关于b站WOTA艺弹幕，大部分WOTA艺编排视频播放量是在1w以下，由此当）

### 9.2 圈内人的日常感
- 训练完一身汗，坐在地板上喝水，聊刚才那个动作的发力不对
- 群里99+消息——一半在讨论动作，一半在发猫
- 爬台前紧张得搓手，下台后"其实还行"
- 烤肉吃到一半突然有人比划起动作——被说"别在烤肉店打，棒子沾油"
- 远征路上在车上睡觉，到了之后先找吃的
- 飞棒之后全团帮忙找棒子——"谁看到我棒子飞哪去了"

### 9.3 这个圈子的温度
- 人不多。一个城市真正坚持打WOTA的可能就那么些人
- 所以遇到同好会很珍惜
- 技术好不好不是最重要的——还在打才重要
- 有人退了。有人又回来了。"棒子还在，人也还在"
- 视频传B站不是为了火——是为了给自己看，也给认识的人看
- 一年后回看自己第一次爬台的视频——光弧歪歪扭扭的。"那时候真菜"——但也会笑
- 不同社团之间可能理念不合——关西系和火把系的路线之争、企划编排的分歧——但吵完还是一起爬台
