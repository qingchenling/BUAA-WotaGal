# 叶子线修订说明

基础文件：`叶子线(1).docx`（1006 段）。修订后：`叶子线_修订版.docx`。

改动原则来自 `角色心理参考.md` 里新增的「学期时间线」：叶子只有三条线——直博班课业（背景）、学生会（只到 W3）、社团行政（主线）。

## 逐条改动

### 1. W12 累的理由里去掉学生会（她已退出）

原：
```
叶子：「滚啊~我上课和学生会工作加一起也很累的好不好」
```

改：
```
叶子：「滚啊~我上课加实验也很累的好不好」
```

### 2. W12 学生会改成过去时，并点明是她退出的前一件事

原：
```
叶子：「正好我在学生会工作了半年，积攒了很多安排活动、晚会的经验」
```

改：
```
叶子：「迎新晚会那次是我在学生会干的最后一件正事，流程我熟」
```

### 3. W13 学生会改成过去时

原：
```
叶子：「之前在学生会我就是负责这些的。走的学院通道，上周就把活动方案和安全预案传上去了。挂靠我们学院团委，老师熟，审得快」
```

改：
```
叶子：「迎新晚会那阵子跑过这套流程。走的学院通道，上周就把活动方案和安全预案传上去了。挂靠我们学院团委，老师熟，审得快」
```

### 4. 去掉「入党」——大一上只是交申请书，不占时间

原：
```
玩家：「那你的绩点、入党、竞赛和学生会……?」
```

改：
```
玩家：「那你的绩点、竞赛……?」
```

### 5. 新：她其实已经放弃了一样东西

原：
```
叶子：「能兼顾，比如每周这会儿有个机器人竞赛的实验数据要我去盯，正好排周常后面」
```

改：
```
叶子：「学生会上个月退了。」
```

### 6. 新：把退出说得像清理待办

原：
```
叶子：「我能平衡好」
```

改：
```
叶子：「迎新晚会完了就没什么事，留着占时间。」
```

### 7. 新：把竞赛明确成「排在后面」而不是并行的第五件事

原：
```
叶子：「迎新晚会完了就没什么事，留着占时间。」
```

改：
```
玩家：「诶？」
叶子：「竞赛的实验数据排在周常后面，能兼顾。」
```

### 8. 新：她自己拒绝「超人」这个说法，落成口头禅「是排班」

原：
```
玩家：「你简直是超人！」
```

改：
```
玩家：「你简直是超人！」
叶子：「不是超人。」
叶子：「是排班。」
```

### 9. W13 新插入：失衡不解释，只报排班

原：
```
叶子：「挂靠学院算学院活动，审批层级少，但安全责任算学院头上，方案做细点就行了」（跟方案没什么关系吧）
```

改：
```
玩家：「你那边呢，实验数据跑完了？」
叶子：「排到下周了。」
玩家：「来得及？」
叶子：「调得过来。」
```

### 10. W15 组会是她研一的灰白才有的，换成开题报告

原：
```
叶子：「组会报告没写完，但我脑子里全是审批流程的材料」
```

改：
```
叶子：「开题报告一个字没写，但我脑子里全是审批流程的材料」
```

### 11. W15 去掉学生会例会，换成她自己的课业

原：
```
叶子：「学生会例会材料我还没开始写，但我在算消防不合格的那家整改期能否赶得及……」（改）
```

改：
```
叶子：「连下周的实验预习都没做，可我还在算消防不合格的那家整改期赶不赶得及」
```
