## W0 报到：计划之外

【今年，我做了件大学计划外的事。但我还想继续尝试下去。】

笔尖停在纸上。台灯把纸照成暖黄色，像一小块被留在桌面上的黄昏。

我被自己吓了一跳。“计划外”这三个字，第一次出现在我的字典里。

它意味着这件事不在任何一张计划表上。没有截止日期，没有妈妈的支持，也不会有哪张证书证明我的努力没有白费。

小学时，我的作业总能在学校写完，回家后就读书架上的“各国名著”。这样妈妈高兴，她可以在亲戚面前说：“叶子这孩子，就是让人省心。”

初中，班主任说，叶子，你稳重，来当班长吧。高中，年级主任说，省级三好学生，你上吧。直博班、奖学金、竞赛、学生会——所有的选项都正确，正确得像一条已经铺好的轨道。

我的简历上排满了奖项与职务，像一面被擦得太亮的墙。可我从没问过自己，墙面后面是什么。

现在回头看，那些不是夸奖，是期待。我满足了期待，他们就会继续期待。直到某一天，我发现我不知道自己想要什么。

我合上这学期新换的手账本，想起那个昏昏欲睡的下午。

报到那天，我们在南站碰头。我比约定时间早到了二十分钟，站在出站口，把新生手册卷成筒，又抚平。

他从出租车里出来时，头发比高中长了些，旧 T 恤的领口洗得松垮，行李箱的轮子在地砖上发出一路磕磕绊绊的响。他冲我挥手，笑得像暑假作业终于写完。

“你迟到了。”我说。

“车堵。”他说。

“我给你发了三条消息。”

“手机在包里。”

我懒得拆穿他。出站后，他在出租车后座靠着车窗睡着了，额头磕在玻璃上，磕一下，醒一下，又睡过去。阳光从他睫毛上滑过去，像一条很慢的鱼。

他一点都没变。

暑假里，听说他又有了新爱好：半夜在阳台上练荧光棒，光甩到对面楼，邻居家小孩跟他妈说，楼里可能有间谍。我听完只问了一句：“他最后练成了吗？”没人答得上来。

他的爱好换得太勤。羽毛球、摄影、五十音图，每一样都轰轰烈烈地开始，悄无声息地结束，像一条健忘的金鱼。这次大概也一样。

到了校门口，我把他拍醒。他迷迷糊糊应了一声，仰头看着“北京航空航天大学”几个字，嘴微微张着，像一条被冲上岸的金鱼。

他终于如愿来到了这里。

我丢下一句“宿舍在那边，我先走了”，转身往女生宿舍走。走出去几步，又回头看了一眼。他还站在原地，仰着头，阳光落在他脸上。

那一刻我忽然想：他大概真的会在这里，做出一些我计划之外的事。

// 转场动画：叶子视角

// BG 咏曼剧场·舞蹈房门外

开学前的迎新晚会彩排，我负责流程和点位。彩排开始前，我沿着剧场走了一遍，确认话筒、灯光、上下场口，一切无误，才到门外透风。

剧场旁边的舞蹈房，门虚掩着。红蓝两色的光从门缝里漏出来，落在走廊的地砖上，像有人把一小段彩虹折断了，丢在那里。

我鬼使神差地走过去。

镜面墙把整间屋子折成好几层。木地板上有一层薄薄的灰，被脚步蹭出几道亮痕。他站在一个女生身后，学着她的动作，两根发光的棒子在手里别别扭扭地转。肩膀太僵，手腕太慢，光弧断成几截，像一条没接好的线。

可他的眼睛是亮的。

明明没有观众，明明动作笨拙得可笑，他脸上的笑却像发现了世上最大的宝藏。那种笑，我在任何一张奖状上都没见过。

我也想要那个笑容。

“叶子！来看一下这个走位——”

身后的叫声惊醒了我。我应了一声，走回剧场。后来我没有跟他提过那天看见的第一次练习。

// BG 操场·百团大战

百团那天中午，我趁着午饭时间到操场找他们。

他们在操场角落里借了友社摊位的一角，拉开一幅易拉宝，几个人蹲在旁边。林若站在最前面，手里转着一根没亮的棒，说话的时候，眼睛看着人。

“wota 艺是一种通过挥棒和呐喊，向别人传达自己的热情的形式。”

我看着她说话时的表情，忽然觉得，“热情”这个词，像是为他量身定做的。

他不是在“学”什么东西。他是把心里烧着的那团火，用手里的棒划出来给人看。

那种事我做不到。不是我没有热情，而是我习惯先问自己：这件事有什么用。等我把答案想清楚，热度已经凉了。

他不会。他甚至不觉得需要问。

他站在那儿，握着发光的棒，像独自面对世界的勇者。

我大概打不出他那样的光弧。但我想站到那道光旁边，看看它是怎么亮起来的。

“听起来很有意思。”我说，“那我也来试试吧。”

林若看了我一眼。她的目光很直，像一把尺。

“最好能按时来，认真练。”

“嗯。”我说，“我先来试试。一会儿还有个会，我先走啦。”

// CG 亮屏手机

那天晚上，开完会，吃完饭，回到宿舍，洗完澡，我躺在床上。

很神奇。明明今晚原定要学习软件的使用，可内心就是平静不下来。

回过神时，我已经加入了宅艺研的企鹅群。明明我知道，它可能会挤占我大量的学习时间。

这一定不符合我原先的计划安排，可当时我就是想这么做。

我翻了一遍公告和群文件。训练排表、技名推荐、过往视频。信息很散，有些是 B 站链接，有些是聊天记录里的临时文件。

毕竟进了群，名义上也算加入宅艺研了，还是要研究一下这些内容。

我这样说服了自己。

// BG 咏曼剧场

后来的训练，我几乎都会去。

带着三脚架和笔记本电脑，找一处可以工作的地方，看他们练。

看他把同一个雷蛇圈打一百遍，直到肩膀酸得抬不起来。林若在旁边指出问题，他就甩甩胳膊，再来。

看他在休息时蹲在地上翻手机，忽然蹦起来，膝盖差点撞上把杆，喊一声“我好像知道问题在哪了”，然后继续打。

不知道从什么时候开始，我注意的不再是他坚持了多久，而是他打艺时的体态、挥洒的光弧、那个筋疲力尽之后还要再来一次的眼神。

还有他每次失误后，先笑一下，再重来的那股劲。

// 黑屏转场

// BG 舞台·第一次爬台

第一次爬台，我在台下帮他们录视频。

舞台是临时争取来的。各学院晚会的节目一般提前一两周就定死了，能塞进一个 wota 节目，已经是叶子——是我——跑了许多趟办公室的结果。

光棒亮起来的一瞬间，全场“喔”了一声。我竟生出了一点自豪。

了解 wota 之后，我认为这样的活动值得登台，他们的努力更应该被认可。

学院同意了，但报销的额度，按我的了解，不够他们编排半首歌的化棒预算。

可看到彩排视频，我最终还是原封不动地传了上去。

他们打完了所有动作。他有几个地方慢了几拍，但完整地打了下来，最后摆了一个很孩子气的、帅气的 pose。

他在看着我，他在笑。那个眼神不同于他以前爱好“结束”时的样子，那是“我还想再来一次”的眼神。

演出结束，大家 AA。我负责收钱，最后差的那一点，我用自己的奖学金补上了。负责采购的学姐问我为什么，我说，算我提前交的社费。

不是逞强。我只是不想让这场演出，在账单上留下一个缺口。

好奇怪。明明我没有参与进去，为什么要为他们努力到这种程度？

// CG 亮屏手机

晚上回到宿舍，群里开了新话题。

宅艺研太显眼，为了避风头，得换个名字。

林若提“零焲”“待ち火”；灰白提了“星火”；夜凪提了“光痕”。

群里的消息一条一条往上翻，没有一条能停下来。

我打开笔记本，翻了翻之前随手记的几个词。

“焲”这个字，我偶然见过。本意是火光，但它把 wota 的神秘与绚丽，具象成了一个字。

火光，不只是光，还有光在燃着那一瞬间的状态。

“痕”，是痕迹，是光划过去之后留下来的东西。

我在备忘录里打了几遍，一遍遍地品着这个名字的味道。

最后，我把这个名字和我的想法粘进了群聊。

发完再一细看，羞耻感瞬间涌上心头。

就像菜市场讨价还价的热闹里，突然有人掏出了 PPT 开始汇报工作。

群里安静了下来。

然后，拯救我的是——

玩家：叶子，有没有人对你说过，你真的很有中二的天赋。

看到这句话，我愣了一瞬。

那句话像一颗小石子投进水里，把我的认真荡成了波纹。

叶子：滚啊。

手比大脑先一步进行了反驳。

我知道他在用他的方式接住我的话。他怕我的话说得太认真了，没人接会很尴尬。他用了一句调侃，把气氛轻轻托了一下。

可我还是有点说不出来的感觉。

我想告诉他，我是认真想出来的。

我想了很久才想出来，又想了更久才打出来。那些话不是临场发挥，是我确实认为如此。

光走得太快了。它亮起来、划过去、消失，甚至来不及被确认。

但痕迹能被留下来，是光来过的证据。

因为支撑我留在那里的，大概也是这样的东西——光走过之后，还能被人看到的东西。

夜凪：噗。

灰白：确实。

我锁了屏。

他说我有“中二的天赋”。

他不知道的是，我写出“光对黑暗说我来过”的时候，脑子里想的是他。

是他站在舞蹈房里，对着镜子，把同一道光弧打了一遍又一遍的样子。

他一遍又一遍地告诉我，那没被光浸润过的黑暗：“来吧，这里有你未曾见过的风景。”

我知道他的痕迹留下来了。留在了门缝外的那个夜晚，留在了百团操场的那个正午，留在了我相机三脚架后这个傍晚，取景框中的那几秒。

// BG 烤肉店

烤盘滋滋作响，炭火的烟裹着肉香往上飘。玻璃杯碰在一起，脆响落进喧闹里。

开学前我写了三页学期规划。绩点、竞赛、学生会晋升，每一项都卡好了节点，精确到周。

我从未想过，临近期末时我还会坐在烤肉店里，陪一群打荧光棒的人庆祝学期收官。

灰白把肉片烤糊了，夜凪抢过去塞进嘴里。林若绷着脸说自己没笑，耳尖却泛着浅红。

“我作证，笑了。”

话说出口，我才开始愣神。

换作往常，我永远是人群里最稳妥、最端着的那个，不会凑这种热闹。

但在这里，不用做直博生，不用做学生干部。

我只是叶子。

// 黑屏转场

林若轻声说“大家辛苦了，谢谢大家”的时候，整桌忽然静了。

她的目光扫过来，对着我轻轻点了点头。眼神很认真，没有半分敷衍。

之前总觉得自己像个局外人。

从不上手打艺，大多时候只是抱着电脑坐在角落，录视频、整理资料。总觉得我只是顺路搭把手，算不得真正的社员。我甚至没有自己的棒。

但那一瞬间，我意识到，我早就是焲痕的一份子了。

这件完全偏离规划的事，这群吵吵闹闹的人，还有这个永远一腔热血往前冲的家伙。

是我这学期，最不后悔的意外。

看来下学期的规划表，要给焲痕留一个重要的位置了。

寒假先去接触高校联的后勤组织和其他学校吧，做点我能做的事。

## W11 名单与远征

// BG 咏曼剧场

“假期过得怎么样？我旅游玩爽了！”

“梅奔演唱会 YYDS！现场厄介差点给我送走。”

“苦命呀，我在学校做项目，一直都没走。”

“三校联合企划你们都没忘吧，马上就要开始了。”

“当然没忘。”我说，“就等这一天了。”

我在旁边把电脑打开，等他们闹完，才把屏幕转过去。

“我进高校联的 staff 群了，最终的节目单我发群里。”

“咱们 wota 类节目比较小众，更多主打的是一个形式新颖，所以最后所有 wota 类一共应该能出两个节目左右。”

“也就是说，wota 节目是各校 wota 社联合表演。”

“假期里我和林若和各校 wota 社以及场地进行了对接，最后我整理了一版爬台站位、歌曲编排的共享文档。”

“歌曲的歌词、上几个人、打什么技、站位、开棒颜色，文档里都有了。”

“后面站位这里，字体颜色代表开棒颜色，然后我把咱们的人用荧光标记了一下。”

“我趣！这么清楚！”

林若凑过来看了一会儿，说：“有叶子这版共享文档，真的帮大忙了。”

她直起身，拍了拍手：“下周我约了北大元火，去远征排练。你们假期练得怎么样？”

“这是我们焲痕在其他学校前首次亮相，最好到时候别像区一样。”

夜凪“嘶”了一声：“我假期基本没练，净瘫着了。就像正经人谁假期学习一样，你们说是吧……啊哈……啊哈哈哈。”

“我练了哦。”灰白说，“学了三四个新技。可能是因为留校做项目没回去，每天晚上都能出来打一打。”

“我没学新的，但是会的几个打了几遍，手感还在。”

“我趣！你们几个浓眉大眼的竟然集体背叛我！”

林若脸上扯出了一个“和善”的笑容。

夜凪：“呃呃呃……社长……一个假期不见，你更爱笑了哈……”

笑容更“核善”了。

“打艺就像舞萌的出勤，那是每天必不可少滴——你怎么就不懂呢？”

“我还可以交流地下艺啊！龙之矛、诸刃啥的，这个假期学了不少呢……”

“啊，还有一条消息。”我说，“假期飞梦老群决定要重开社庆了。”

“我趣！飞梦！忠诚！”

“嗯……不过现在还在筹划阶段。”林若说，“能成的话，我们到时候估计要出节目。”

“冬梦节能重开了？！”

“我们去打冬梦节！？”

“还早着呢。现在估计只是草台班子，可以先记着。”

林若顿了顿，又看向夜凪：“但是……夜凪你这假期……？”

“嘶……我这就复健！不！加练！一周四次，不够就五次！！”

灰白举手：“不过这学期训练时间能换吗？之后每周这会儿我有组会了。”

“我周五晚上有实验，周日晚上有科研课堂。”我说。

“嗯，她科研课堂拉着我一块儿报的。”玩家补了一句，“这拖延课堂是真的拖堂，还查考勤。”

“我二四晚上有课。”

“我二五晚上有课……虽然周二的课能翘吧……但没用啊。”

“得，那还是周六吧。”灰白说，“我自己再找时间练。彩排我尽量来。”

“忙，都忙点好啊。”

“行了别摸鱼了你。”林若把棒往包里一塞，“该说的都说完了，赶紧开练。先都来摸个底。”

// 黑屏转场

// BG 北大·百周年纪念讲堂侧下沉广场（夜）

从东门刷身份证进入，绕过体育馆、操场，来到百周年纪念讲堂侧面。

这一小块下沉空间，便是北大 wota 社水月 Mizuki 活动的场所。

路灯从树冠里漏下来，把地面照出一块一块的暖黄。有人穿着痛衣，有人披着法批，棒子还没亮，笑声先到了。

“焲痕吧，欢迎欢迎——”

林若作为焲痕社唯一还曾与外校有过交流的人，正努力地进行着寒暄。

我悄悄地凑过去：“他们穿的什么呀，感觉怪怪的。”

“痛衣和法批啦。”玩家说，“这种是浓度高的老资历。”

“都是大家老资历喵。”夜凪说，“听说清华水木的也来了，我已经迫不及待要启动北航拳了。”

“诶！你是叶子吧？”一个外校女生忽然拉住我，“听林若说，爬台编排的模板是你出的？太天才了吧——”

我还没来得及回答，就被她薅走了。被薅走时，我回头冲玩家眨了眨眼。

“叶子这么强的吗？”玩家在身后感叹，“寒假发明了个编排模板，已经有如此高的圈内知名度了。”

“感觉咱们这边好冷清啊。”灰白说，“不，这应该是尴尬吧。”

“今天的风儿甚是喧嚣。”
