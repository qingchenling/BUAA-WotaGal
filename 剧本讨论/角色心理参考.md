# 角色心理参考（内部文档）

> **本文档仅供编剧参考，不直接用于游戏内文本。**
>
> 目的：帮助编剧准确把握每个角色在剧情各阶段的真实心理状态，从而写出"角色只露出冰山一角但观众能感觉到水下巨大体积"的效果。

---

## 使用原则

1. 本文档记录角色**真实在想什么**——这些内容绝大多数**不应该**直接写进剧本
2. 剧本中角色展现的是**冰山露出水面的1/10**——神态、动作、短台词、沉默
3. 编剧掌握100%的心理真相，观众通过这1/10去感受和猜测
4. 偶尔在关键节点可以给观众多露出一些（比如叶子W19进线独白），但这是稀缺资源

---

## 一、叶子 — 心理真相 vs 剧本呈现

### 叶子线情绪基调

- **核心问题**：除了学习和成绩，我还可以喜欢什么
- **氛围**：轻快、日常、慢慢被吸引
- **社团对角色**：多了一个好玩的地方。生活变丰富了。
- **感情进展**：日常中慢慢升温——小动作、小表情、小发现
- **以前的生活**：挺好的。成绩好、直博班、按部就班——没什么问题。现在多了一扇窗。

### W0-W4：接触期——"这什么东西，好像有点好玩"

| 阶段 | 她在想什么（编剧知道） | 她表现出来什么（观众看到） |
|------|----------------------|--------------------------|
| W0 入学 | 和他同一所大学。在陌生环境里至少有一个认识的人。大学生活——除了读书考试，是不是也该有点别的。 | 冷淡的一句"快到了，起来吧"。当晚在宿舍看窗外新生玩荧光棒——一个普通女生在想"大学要不要玩一下"。 |
| W1 食堂相遇 | 他在讲社团的事。眼睛里有我从未见过的光。那个表情让我有点在意——不是不好，是我没见过。 | "社团是什么时候都可以加。但你在强基班，GPA掉下来会很麻烦。"——标准的叶子式劝诫。语气平淡。但事后想了一下那个表情。就一下。 |
| W2 图书馆 | 他让我帮他选棒子。参数很简单。社长是女的？——问完自己都不知道为什么问。夕阳下他看视频时手指在比划动作——看了好一会儿。 | 快速分析参数，选"大火"。随口问"社长是女的？"——然后立刻补"我说开会时别玩手机"。两个人都笑了。 |
| W3 咏曼剧场门外 | 班会结束。班主任说我"最有规划"。走出教学楼——发现自己走到了咏曼剧场。没解释为什么。就是走过来了。门缝里看到林若在纠正他的发力——"手腕再往外一点，力从肘关节走"。他们凑在三脚架前看回放，逐帧找光弧不圆的地方。那个表情——站在门外看了很久。回去搜了WOTA。搜了"WOTA艺 教学"。又搜了"大学社团 场地申请"。浏览器开了七个标签页。没意识到自己在做什么。但台灯亮到了很晚。 | **观众只看到**：她从剧场方向走回宿舍（没有解释为什么经过那里）。掏出手机搜索WOTA。（一个动作，没有内心独白。） |
| W4 百团 | 他发消息——四个感叹号。他以前不打感叹号。去了百团。不知道为什么要去。站在人群外围看他们打游击招新。不收传单。不评价。就是在旁边待了一下午。收摊后主角说"你来了就好"——满头汗。回去路上在备忘录里打了场地申请流程。打完自己愣了一下，然后笑了——不是"审视人生"，是"我怎么在写这个"的那种好笑。 | 来了百团。站在台阶上旁观。说"我又没做什么"。收摊后在备忘录里打字——观众会以为是在写报道。只有到后期（W10+），观众才会隐约意识到她那天打的是场地申请流程。 |

> **W0-W4要点**：W0结尾不要哲学独白——就一个普通女生。W3门缝的训练描写用真实细节（发力感、录视频回放）。W4她写完场地申请之后自己笑了——"我怎么在写这个。"

### W13-W16：有点认真了——"这事好像跟我也有关系了"

| 阶段 | 她在想什么（编剧知道） | 她表现出来什么（观众看到） |
|------|----------------------|--------------------------|
| W13 网暴 | 他被挂了。深夜发来"有点烦"——他在压着。截图发来了。B站社区规范第3.2条——看一遍就知道了。和看场地审批规定一样。和看社团续期流程一样。规则写在那里，就会看。举报了。48小时内有结果。这两天别看评论区。 | 观众看到：她冷静地说"截图给我""我来处理"。半小时后发来B站举报链接。主角问"你怎么会写举报材料"——她说「B站社区规范第3.2条。看一遍就知道了。」——不是因为她经历过什么。她就是会看社区规范的那种人。和记住表格编号是同一个性格特质。不需要创伤。不需要故事。就是看了一遍。很叶子。 |
| W14 排练计划 | 三校演出排练进度需要有人统筹。拉了一个Excel——每个人的空闲时段、当前熟练度、需要加练的段落。就是排个表。灰白说"你是学数据分析的？"——Excel拉一下就有了。就是平均数。为什么有人觉得拉个Excel算平均数需要专门学。 | 在群里发了一份排练进度统筹表。灰白："你是学数据分析的？" 叶子："Excel拉一下就有了。就是平均数。"——语气是真的觉得这很简单。不是谦虚，不是炫耀。夜凪回了句「大数据分析（狗头）」——群里刷了一排表情包。后来林若去柜子里把计划表打印出来夹进文件夹——主角看到了。叶子不知道。 |
| W15 场地取消 | 训练室门上贴了场地取消通知。要去解决。焲痕社的场地不能没。跑了三天——发现对方同时段占了两个场地，拿出规定要求释放空余。方老师问学什么的——工科。两次。不是谦虚，是实事求是。 | 观众看到：叶子站出来说"我去找学院"——声音不大。林若点了点头。三天后场地恢复。夜凪从学工办学弟那里听说：她跑了三天，逐条对细则。方老师问她学什么的——她说工科。两次。 |
| W16 方老师 | 主角去学工办交表。方老师把申诉材料当模板——"那个工科直博生——毕业了申论不用复习。"主角在群里说了。让方老师准备头疼——下个月还要交一份。群里在笑。我也笑了一下。 | 方老师："那个工科直博生——毕业了申论不用复习。" 主角在群里说"方老师问起工科直博生"。叶子："告诉方老师，下个月还要交一份。让她准备头疼。" 林若：「。」（焲痕社群聊里的句号 = "我在笑但我不说"） |

> **W13-W16要点**：整体轻快有梗。W13的新理由让叶子更酷了——不是因为她受过伤所以坚强，而是因为她本来就是那种觉得"规则写在那里当然应该读"的人。W14叶子不说"直博班"不说"概率论"——她嘴里永远是"Excel"、"平均数"、"看一遍就知道了"。W15场地问题保持真实性。W16"让她准备头疼"——叶子式的玩笑。

### W17-W19：演出前——"……好像不只是顺便了"

| 阶段 | 她在想什么（编剧知道） | 她表现出来什么（观众看到） |
|------|----------------------|--------------------------|
| W17 灰白退社 | 灰白来收拾化棒。林若说"等你回来"。QQ群聊等级——灰白在群里待了那么久，几乎每天都在。记录不能缺一个人。下次我会记完整的。 | 观众看到叶子在灰白走后翻了翻手机上的QQ群——灰白的群聊等级。她说"下次我会记完整的"——手指按着纸边，很轻。 |
| W18 节目单 | 在做一本A5册子。封面「焲痕社·未完——」。不是普通节目单。太厚了。他路过瞄到了——岔开话题。还没到给他看的时候。 | 主角在图书馆看到叶子在做一本A5册子。她说"节目单"。路过时瞄到封面：「焲痕社·未完——」问是什么，她把册子翻了个面。"水打好了就坐下。你挡光了。"主角觉得那不是普通节目单——太厚了。 |
| **W19 进线关键** | 凌晨一点。明天演出。他在紧张——紧张的时候搓手，我知道的。他说"不确定没有我的话这个社团会不会更好"。我想了很多东西。W3门缝。W4百团备忘录。W8林若说谢谢。W15场地申诉。W17灰白的群聊等级。我做这些不是因为他需要我帮忙。是因为他在台上的时候——是我见过他最像他自己的时候。我以前从不知道一个人可以这么完整地成为自己。他在台下笨手笨脚，三分钟热度，什么都会半途而废。但在台上——他从来不放弃。我没有在台上站过。但我站在台下，看着他——那是我最接近"成为自己"的时刻。今晚要告诉他一部分。不是全部。是一部分。足够让他明天上台的时候知道——有人在看。不是看光弧。是看他。 | **观众看到**：凌晨对话。叶子说"因为你在台上的时候，是我见过你最像你自己的时候"。这是W3-W18所有未说出口的话——被压缩成一句。观众感受到巨大的情感重量，但不被告知所有细节。留白让这句台词更有力量。 |

> **W19是整条线唯一一次她说这么多话。前面十八周的全线铺垫——那些她没说出口的东西——全部压缩进了这段对话。** 语气不是"告白"，不是"掏心掏肺"——就是凌晨一点，用平时那种平的语气，说了真话。说完之后第二天照常去第三排靠走廊坐着。

## 二、林若 — 心理真相 vs 剧本呈现

### 关键心理真相

| 阶段 | 她在想什么（编剧知道） | 她表现出来什么（观众看到） |
|------|----------------------|--------------------------|
| 序章 宋柯离开 | 他说"从没觉得打艺开心过"。是那次爬台效果不够好吗。是我的技术太差了。我拖累了他。他教了我那么多——OAD怎么发力，手腕怎么转——我却没有好到让他留下来。以后不能再这样了。必须打到没有瑕疵。打到没有人会因为我技术不够而离开。 | 站在原地。没有追上去。没有哭。只是站在原地——画面渐暗。观众只看到震惊和沉默。她的内心推理全程隐藏在沉默背后。 |
| W1 初见主角 | 这个新生说"想"。他问了几个问题。他没有说"还是算了"。只是一个人。但比没人好。如果他留下来——我不会再让任何人因为我的能力不够而离开。 | "想学？""明天开始。社团只有我一个人。你还想加吗？"——三个短句。观众感受到她的孤独和试探，但不被告知"她在想什么"。 |

| W12 分歧 | 这套技连是宋柯离开前打的最后一套。每一个动作都是他教的。如果改了——就好像他没有存在过。我不敢改。不敢。我不是在追求完美。我是在保护他留下的唯一的东西。主角说"什么才叫够好"——我不知道。我只知道如果打不出这一套，就好像辜负了他。 | "宁可不上台，我也不要打不够好的东西。"——观众听到的是一个严苛社长的宣言。但这句话背后真正的意思是害怕。观众在当下不一定能听出来。到天台（林若线W15）才恍然大悟。 |
| 天台（林若线核心） | 主角说"他不是因为你才走的"。我问他怎么知道。他说"我去找他"——我从来没有想过去找他。我怕确认那句话是真的。也怕确认那句话是假的。如果是假的——那我这一年多在干什么。如果是真的——那我的所有偏执都是有道理的。不敢去。 | **这是林若线唯一一次她主动说长段话。** 观众终于理解她的偏执根源。但她说的时候仍然是低着头、攥着衣角——内心汹涌，表达克制。 |
| 和解后 | 他说不是因为我。不是因为我的技术。不是因为那次爬台。不是因为我不够好。他只是不喜欢那个被网暴的自己。和我的技术没关系。和我没关系。那套技连——不打了。不是因为宋柯不重要。是因为我终于知道——他从来不是因为我的技术留下来，也不会因为我的技术离开。所以我可以打一套新的了。不是替代他的。是加上了我自己的。 | "这段不改，这是我的。"——她说的时候没有哭。没有长篇大论。就这一句。观众知道这句话意味着什么。 |

## 四、主角（玩家角色）— 心理设计原则

### 主角的内心独白——可以写，但要分层次

| 层次 | 可以写什么 | 不能写什么 |
|------|-----------|-----------|
| 即时反应 | "她站在路灯下——是在等我吗？" | "她看到宋柯的那一刻，心里某根弦断了。"（这太全知，主角不可能知道） |
| 感性观察 | "她打完那套技连之后没有看我，但把化棒收得很慢。" | "她其实是在想宋柯。"（主角不确定的事，不能用陈述句） |
| 自我反思 | "我是不是一直在让她担心。" | "她今天来不是为了看演出，是为了看我。"（太确定。主角只能猜测。） |
| 谜团 | "她为什么要帮我。从小学到现在，她总是在我不需要的时候出现——但如果我不需要，她为什么还在这里。在需要的时候，她又会说'不要谢我'。叶子——你到底在想什么。" | 不能给出答案。要在玩家心里种问题。 |

### 关键：玩家与主角的信息差

- **主角看到的 = 玩家看到的**。主角不知道的，玩家也不应该被旁白告知。
- **主角的困惑应该就是玩家的困惑**。比如主角在第6周时隐隐觉得叶子在看什么——不是看光弧，是看他。但他不确定。玩家也不确定。这种不确定是好东西。
- **不要让主角比玩家更敏感**——如果主角读出了连玩家都还没注意到的细节，玩家会觉得被跳过了。反过来，如果主角注意到了一些东西但没得出结论，玩家会自己去想。

## 五、侧面描写的技术工具箱

> 如何在不写内心独白的前提下传达角色的情感状态。

### 1. 动作代替想法
```
❌ 内心独白：她很紧张。这是她第一次踏入训练室。
✅ 动作：她在训练室门外站了七秒才抬手推门。门推开一半，又收回手。重新握了一下拳。推开。
```

### 2. 环境的情绪投射
```
❌ 内心独白：她觉得一切都碎了。这个社团，这些努力，好像全没意义了。
✅ 环境投射：黑板上那张通知的边角没有粘牢，风一吹就卷起来。她盯着那个卷边看了很久。
```

### 3. 沉默的节奏
```
❌ 内心独白：她听到林若说谢谢——这是两年来的第一次。她不知道该怎么回应，心里很乱。
✅ 沉默：林若："谢谢。"她握着两张表格。走廊很长。有一瞬间她们之间的安静比声音更大。然后她把表格翻到下一张。"指导教师那边——我来找。"
```

### 4. 重复中的变化
```
❌ 内心独白：她开始关心这个社团了。不是因为他，是因为她自己。
✅ 重复中的变化：
   W5—— "场地申请流程……"（备忘录开头）
   W8—— "焲痕社·场地"（备注标题）
   W10—— "焲痕社·行政"（文件夹标签名）
   观众通过标签名称的变化，自己得出结论。
```

### 5. 他人视角的折射
```
❌ 直接内心：叶子是社团里最重要的人之一。
✅ 折射：夜凪："那个工科直博生——没有她，我们连训练室都保不住。"
    林若：[在表格上写叶子的名字——行政联系人栏]
    主角："你知道吗。这是你今年写的第三本文件夹了。"
    叶子："第四本。"（笑）
```

### 6. 被看见的细节 = 被感受到的情绪
```
叶子在备忘录里打字时，指尖上洇了一小块墨水——她把笔握得太紧了。
// 一个字没提"紧张"或"认真"，但读者能感觉到。
```

## 六、"视角突破"的使用许可证

> 偶尔需要突破主角视角，给观众看到其他角色的内心。这是重武器——不能当常规武器用。

### 什么时候可以用

| 条件 | 示例 |
|------|------|
| 剧情到了最关键的转折点 | W19叶子进线对话——唯一一次她完整袒露心声 |
| 那个角色的内心是整个场景的唯一核心 | 林若天台独白——林若线核心 |
| 之前的铺垫已经让观众积攒了足够多的"想知道" | 叶子为什么一直帮忙——W3-W18一直在埋，W19才揭 |
| 不在当周剧情的"热区"内，作为独立插曲 | 类似于"叶子视角补"——但一整条线不能超过2-3次 |

### 什么时候不能用

| 禁止场景 | 原因 |
|----------|------|
| 每周固定剧情后都加一段"XX视角补" | 廉价化。观众不再好奇，因为知道下周就会被告知。 |
| 角色每次做出重要行动后立刻解释动机 | 消灭留白。最动人的就是观众自己去想"她为什么要这样做"。 |
| 在同一个场景里频繁切换视角 | 眩晕。galgame不是全知小说。视角一乱，代入感全碎。 |

### 视角突破的集中使用策略

与其每周附一小段，不如整条线攒着，在2-3个关键节点集中释放：

**建议的叶子线视角突破点**（共3处）：
1. **W19 进线对话**（已写）——最大的一处。整条线积攒的情感在这里揭晓一部分。
2. **结局手账递出时**——手账被打开，观众通过手账的内容看到叶子四年来的视角。不是"她现在在想什么"——是手账替她说了。
3. **（可选）W15场地申诉后**——一个非常短的视角突破。仅一句话——她靠在走廊墙上，直博班的群消息在震，她没看。她把申诉材料夹进文件夹。文件夹快满了。——这不是内心独白，是动作。但放在这个位置，它的情感功能等同于一次视角突破。

## 八、关于"玩家心理"的考量清单

写每场戏前，问自己：

1. **玩家现在知道什么？** 检查当前周数之前所有已发生的场景——哪些信息已经给过了，哪些还没有。
2. **玩家现在好奇什么？** 有没有一个悬念正在推进中？这场戏是推进这个悬念，还是戛然而止让悬念继续？
3. **玩家现在应该感受什么？** 紧张？期待？心照不宣？被触动？——选择一种主导情绪。
4. **玩家不应该被直接告知什么？** 哪些真相需要再藏一藏？
5. **这场戏结束后，玩家对X角色的理解应该增加多少？** 从1到10。日常场景可能只+0.5，关键场景+3——不要每场都+3。
6. **如果我是玩家，读到这段会有什么猜测？** 如果猜测太准——信息给多了。如果毫无头绪——信息给少了。

## 九、叶子线情绪递进速查

| 阶段 | 叶子的真实心态 | 对玩家的呈现方式 |
|------|---------------|----------------|
| W0-W4 接触期 | 这什么东西，好像有点好玩 | 行动+短句，好奇但不承认 |
| W5-W9 参与期 | 好像可以顺便帮点忙，反正也不难 | 高效行动，主角事后发现 |
| W10-W12 新学期 | 这个社团还挺好玩的，做记录做上瘾了 | 信息差+轻松互动 |
| W13-W16 认真期 | 这事好像跟我也有关系了，不是"顺便"了 | 冷静行动+叶子式玩笑 |
| W17-W19 演出前 | ……好像不只是顺便了 | W19凌晨唯一一次释放 |
| 结局 | 好吧，已经是生活的一部分了。就这样吧。 | 手账替代告白 |

---

> **一句话总结**：编剧知道冰山全貌。观众只看得到一角。那一角必须好看——形状对、角度对、光线对。至于冰山水下的体积——让观众自己去想象。

> **叶子线的一句话**：不是"她终于找到了自己想做的事"——是"她本来生活也挺好的，但多了一个觉得好玩的地方。然后这个地方慢慢变成了她生活的一部分"。不是颠覆，是扩充。不是拯救，是遇见。
